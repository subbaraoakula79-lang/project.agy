India-first ride-hailing platform — Bike, Auto, and Cab rides.

## Getting Started

## Architecture

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for system design.

## Project Structure

| Path | Description |
|------|-------------|
| `apps/api` | NestJS backend API |
| `apps/rider` | Expo React Native rider app |
| `apps/driver` | Expo React Native driver/captain app |
| `apps/admin` | Next.js admin dashboard |
| `packages/shared-types` | Shared TypeScript types and enums |
| `packages/service-contracts` | Service interface contracts |
| `packages/db` | Prisma schema and seed data |
| `packages/shared-config` | Shared build configuration |
| `docs/` | Documentation |

## Tech Stack

TypeScript • NestJS • React Native/Expo • Next.js • Prisma • SQLite/PostgreSQL • Turborepo
